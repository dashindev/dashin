# dashin-cli

## Install

```bash
$ npm install --global dashin-cli
```


## CLI

```
$ dashin --help

Usage
	Create a new project (Vite or Next.js)
	  $ dashin new {name}
	  $ dashin new {name} --nextjs

Options
    --plugin  with demo plugin
    --doc     with demo document

Examples
  $ dashin new my-dashboard
  Your project "my-dashboard" has been created.
```
