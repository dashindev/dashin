## Local test

**_It takes more time, but the data and permissions are completely controlled by yourself_**

1.Start Strapi service

```shell
cd [Test folder]
git clone https://github.com/dashindev/dashin-example-strapi.git dashin-example-strapi-service
$_ && yarn install
yarn develop
```

2.Preset Dashin

```shell
cd [Test folder]
git clone https://github.com/dashindev/dashin.git dashin-example-strapi
$_ && yarn install

cd packages/dashin
cp example/.env .env.development
```

3.Use environment variables

Replace the content of `.env.development` **_(dashin-example-strapi/packages/dashin/.env.development)_** with the following:

```shell
# Dashin Core

REACT_APP_SITE_NAME=Dashin DEV
REACT_APP_AUTH_PLUGIN=@dashin-dev/auth-strapi
REACT_APP_MAIN_URL=http://localhost:1337/api/v1
REACT_APP_AUTH_URL=http://localhost:1337
REACT_APP_UPLOAD_URL=http://localhost:1337
#REACT_APP_FILE_PREVIEW_URL=
REACT_APP_SITE_URLS=http://192.168.2.2:51802/api/v1, http://192.168.2.2:51803/api/v1
REACT_APP_I18N_CODE=en
REACT_APP_ON_I18N=true
REACT_APP_ON_SETTING=true
REACT_APP_ON_DOC=true
REACT_APP_ON_MOCK=false
REACT_APP_IGNORED_PLUGINS=@dashin-dev/upload-buncms, dashin-plugin-example-blog2
REACT_APP_PATHS_WITHOUT_LAYOUT=/example/about, /example/*
REACT_APP_PATHS_WITHOUT_AUTH=/docs/*
#REACT_APP_NOTIFICATION_PLUGIN=
#REACT_APP_ON_NOTIFICATION_INTERVAL_COUNT=true

# Dashin Plugins

# Upload Plugin
REACT_APP_UPLOAD_STRAPI_ROLE=Admin,Reviewer

# Auth Plugin
REACT_APP_AUTH_STRAPI_ROLE=Admin

```

4.Start Dashin

Run in `dashin` path **_(dashin-example-strapi/packages/dashin/)_**

```shell script
yarn dev
```

Open [http://localhost:1911/](http://localhost:1911/)

Login with any user below (different menus):

- Username: `admin`, `reviewer`, `user`
- Password: `dashin`

Strapi super administrator:

- Dashboard: [`http://localhost:1337/admin/`](http://localhost:1337/admin/)
- Username: `dashin_example_strapi`
- Password: `dashin`

**_Due to the security mechanism of Strapi, Strapi dashboard users and front-end users adopt different APIs. Therefore, in this example, the Strapi super administrator cannot login through dashin._**
